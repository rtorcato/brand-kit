# ai-gemini

Logo and canvas background generated by Google Gemini with `--ai`. Everything else
is the same as [basic](../basic): name and tagline from `package.json`.

```sh
cp .env.example .env    # then fill in GEMINI_API_KEY
npx @rtorcato/brand-kit --ai --ai-provider gemini --ai-prompt "flat geometric line art"
```

- **Provider:** `gemini`, default model `gemini-2.5-flash-image`. Override with `--ai-model`.
- **Key:** `GEMINI_API_KEY`, read from this folder's `.env` (gitignored) or the shell.
- **Style:** `--ai-prompt` is the same in every `ai-*` example, so the
  three differ only by provider.

It saved the art as sources in [`brand/`](brand): `logo.png`,
`background.png`, and a `favicon.svg` that embeds the logo. Re-renders need
no key; run `--ai` again only for new art.
