# ai-openai

Logo and canvas background generated by OpenAI with `--ai`. Everything else
is the same as [basic](../basic): name and tagline from `package.json`.

```sh
cp .env.example .env    # then fill in OPENAI_API_KEY
npx @rtorcato/brand-kit --ai --ai-provider openai --ai-prompt "flat geometric line art"
```

- **Provider:** `openai`, default model `gpt-image-1`. Override with `--ai-model`.
- **Get a key:** [the OpenAI platform](https://platform.openai.com/api-keys) — create a secret key; image generation needs billing enabled.
- **Key:** `OPENAI_API_KEY`, read from this folder's `.env` (gitignored) or the shell.
- **Style:** `--ai-prompt` is the same in every `ai-*` example, so the
  three differ only by provider.

It saved the art as sources in [`brand/`](brand): `logo.png`,
`background.png`, and a `favicon.svg` that embeds the logo. Re-renders need
no key; run `--ai` again only for new art.
