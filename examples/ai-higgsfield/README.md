# ai-higgsfield

Logo and canvas background generated by Higgsfield with `--ai`. Everything else
is the same as [basic](../basic): name and tagline from `package.json`.

```sh
cp .env.example .env    # then fill in HF_API_KEY_ID + HF_API_KEY_SECRET (or HF_KEY=id:secret)
npx @rtorcato/brand-kit --ai --ai-provider higgsfield --ai-prompt "flat geometric line art"
```

- **Provider:** `higgsfield`, default model `higgsfield-ai/soul/v2/standard`. Override with `--ai-model`.
- **Key:** `HF_API_KEY_ID` + `HF_API_KEY_SECRET` (or `HF_KEY=id:secret`), read from this folder's `.env` (gitignored) or the shell.
- **Style:** `--ai-prompt` is the same in every `ai-*` example, so the
  three differ only by provider.

It saved the art as sources in [`brand/`](brand): `logo.png`,
`background.png`, and a `favicon.svg` that embeds the logo. Re-renders need
no key; run `--ai` again only for new art.
